# Weather App

## Overview
This is a browser-based weather application built using HTML, CSS, and JavaScript.  
It fetches real-time weather data from the OpenWeather API and dynamically updates the UI based on the selected city.

## Features
- Displays current, minimum, and maximum temperature
- Temperature-based color styling
- Weather-based animated background
- Default city loads on page open
- Smooth fade-in animation on load
- Dynamic weather icons

## Technologies Used
- HTML
- CSS (Flexbox, animations)
- JavaScript (Fetch API, DOM manipulation)
- OpenWeather API

## How to Run
1. Clone this repository.
2. Open `index.html` in your browser.
3. Enter a city name and click the button.

Note: You will need your own OpenWeather API key.
